# Venture Primary Homepage v0.8

This patch restores Venture's original public visual identity on the Today screen:

- warm cream base
- Venture yellow
- Venture red
- deep ink outlines and type
- coral-pink secondary accent

It also replaces the quiet dashboard feeling with a more active city-discovery homepage:

- animated Winnipeg ticker
- bold time-aware hero
- natural-language search
- four large discovery modes
- featured Venture Pick
- stronger outing-builder card
- exploration progress card
- editorial discovery rails

The Today screen remains app-first and mobile-first. Search, New to Me, outing building, visit history, saves, and existing listing links remain connected.
