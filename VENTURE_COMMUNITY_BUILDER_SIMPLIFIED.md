# Venture Community Builder v1.6

This patch simplifies `/admin/community` into a three-step workflow:

1. Build the itinerary
2. Edit the experience
3. Manage guests and attendance

The initial creation form now shows only the essential fields. Optional host, meeting, accessibility, dietary, cost and URL details live under an Advanced details panel.

No database migration is required.

The browser hydration warning shown by Grammarly is not caused by Venture. Disable Grammarly for localhost or use an extension-free browser profile while developing.
