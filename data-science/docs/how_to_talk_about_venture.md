# How to Talk About Venture

## One-sentence product explanation

Venture is a trusted Winnipeg discovery platform that helps people find events and places, then turns them into a practical, route-aware outing.

## One-sentence data explanation

Venture combines verified city inventory with anonymous product analytics to measure whether users can discover, build, save, and share worthwhile plans.

## Data analyst framing

“I designed a controlled event taxonomy, built funnel and cohort reporting, monitored data quality, measured inventory coverage, and created admin exports for repeatable analysis.”

## Data scientist framing

“I versioned a rule-based recommendation system, defined offline and behavioural evaluation metrics, built an experiment framework with confidence intervals and guardrails, and documented the model's assumptions and limitations.”

## Honest distinction

The current recommender is a transparent scoring and constraint system, not a trained machine-learning model. That is a strength at the present stage because Venture needs interpretability and better data before a more complex model can be justified.
